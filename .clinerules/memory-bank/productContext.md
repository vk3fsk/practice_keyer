# Product Context

## Why This Project Exists

### Problem Statement
Learning and practicing Morse code (CW) requires effective tools. Existing memory keyers are either:
- Expensive commercial ham radio equipment
- Complex multi-function devices with steep learning curves
- Lack flexibility for practicing at different speeds
- Don't offer enough memory slots for varied messages

### Solution
Practice Keyer provides a simple, dedicated hardware device for CW practice with:
- Physical paddle input for authentic keying experience
- Variable speed control (5-40 WPM) via potentiometer
- 4 memory slots for recording and replaying messages
- Playback at adjustable speeds for learning progression
- Persistent storage (recordings survive power cycles)
- Simple one-button recording interface

## User Experience Goals

### Practice Flow
1. **Setup**: User connects paddle, adjusts speed potentiometer
2. **Key Practice**: User sends Morse code with paddle, hears buzzer sidetone
3. **Record**: User records a message to a memory slot
4. **Replay**: User plays back recordings at different speeds for learning
5. **Repeat**: User practices the same message at various speeds

### Key Interactions
- **Paddle Keying**: Natural iambic paddle input for dit/dah
- **Speed Adjustment**: Real-time WPM control via potentiometer
- **Recording**: One-button recording with LED indicator
- **Playback**: Single button per slot for instant replay
- **Sidetone Feedback**: Immediate audio confirmation (600Hz buzzer)

### User Experience Principles
- **Simplicity**: Minimal buttons, intuitive operation
- **Immediacy**: Instant audio feedback during keying
- **Flexibility**: Practice at any speed (5-40 WPM)
- **Reliability**: Hardware-based, no software crashes
- **Persistence**: Recordings saved to flash memory

## Target Audience

### Primary Users
- **Ham Radio Operators**: Learning or maintaining CW proficiency
- **CW Enthusiasts**: Morse code hobbyists and operators
- **Radio Contesters**: Practicing common contest exchanges
- **Emergency Communications**: Preparing standard messages

### User Needs
- Realistic paddle keying experience
- Variable speed for building proficiency
- Message recording for repeated practice
- Simple, reliable operation
- Portable, standalone device (no computer required)

## Success Metrics
- User can record and replay 100+ character messages
- Smooth speed adjustment from 5-40 WPM
- Recordings persist across power cycles
- Reliable button/paddle operation (no false triggers)
- Accurate timing reproduction during playback

## Value Proposition
A simple, affordable, dedicated memory keyer for serious CW practice. Unlike expensive commercial units, this provides essential features (4 slots, variable playback speed, persistent storage) in a straightforward, single-purpose device that ham radio operators can build themselves.
